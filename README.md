# Smart Bank Token Management System

A clean, beginner-friendly Java Spring Boot project for managing customer tokens in a banking queue.

## Project Goal
This is a college prototype for a smart bank token management system. It allows customers to request a token, choose a service, choose priority, and track their queue status. Staff can view waiting tokens, call the next customer, assign counters, and complete the service flow.

## Tech Stack
- Java 17+
- Spring Boot
- Maven
- MySQL
- HTML, CSS, JavaScript
- JUnit
- Git + GitHub
